## Quem somos

Somos a equipe **RAIDENS**, do **SESI 192 de Alumínio**, em São Paulo. Projetamos, construímos e programamos robôs autônomos para competições como a **[Olimpíada Brasileira de Robótica (OBR)](https://obr.robocup.org.br/)** e a **[Mostra Nacional de Robótica (MNR)](https://mnr.robocup.org.br/)**.

Tudo o que desenvolvemos fica aberto aqui, organizado para que novos integrantes aprendam com o que já foi feito e para que outras equipes possam aproveitar.
